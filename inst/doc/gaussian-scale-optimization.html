1 Why optimize sigma inside the model?

The original radish workflow for raster smoothing usually worked in two steps:

  1. Smooth each raster at several candidate scales.
  2. Fit a resistance model to each smoothed raster surface and compare the fits.

That approach is still useful, but it treats scale as an outer tuning parameter. The new native Gaussian conductance system in terradish moves the scale parameter into the conductance model itself, so the optimizer can update:

  • the conductance coefficient(s), and
  • the smoothing scale(s)

in the same likelihood calculation.

This vignette shows the current implementation of that idea using gaussian_smoothed_loglinear_conductance().

2 What sigma means here

For a raster covariate x, the Gaussian scale-aware model first smooths the raster with a Gaussian kernel and then uses the smoothed values in the usual log-linear conductance model.

Conceptually:

\[C_i = \exp(\beta \cdot x_{i,\sigma})\]

where:

  • \(x_{i,\sigma}\) is the Gaussian-smoothed raster value at cell i
  • \(\beta\) is the conductance coefficient
  • \(\sigma\) controls how broad the smoothing kernel is

Small sigma means that the raster is averaged over a narrow neighborhood. Large sigma means that it is averaged over a broader neighborhood. Here, sigma is a Gaussian smoothing scale in the raster’s map units. It is not an estimate of dispersal distance, home-range size, movement distance, or the spatial scale of a causal ecological process.

2.1 Are there limits on sigma?

Yes. terradish now estimates sigma directly on its natural distance scale and fits it within explicit lower and upper bounds.

By default, those bounds are data-derived:

  • the lower bound is half of the mean raster cell width
  • the upper bound is the diagonal length of the retained raster extent

You can override those defaults with sigma_lower = and sigma_upper = when you create the conductance model.

Internally, the optimizer now works on a converted sigma scale by default, using approximate cell-width units. The fitted coefficients and summaries are still reported back in map units for users, so the conversion helps the optimization without changing the interpretation target.

Two practical caveats are worth keeping in mind:

  • factor-valued raster layers are rejected for this Gaussian conductance model rather than being treated as scalable predictors
  • leverage / partial_X diagnostics are still unavailable, because the current diagnostic machinery assumes a one-to-one match between conductance parameters and design-matrix covariates

3 Worked example

We will fit a small staged example using the melip data. To keep the vignette fast and stable, we will:

  • use only eight sampling sites
  • start with one raster covariate (forestcover)
  • use mlpe as the measurement model, because the response matrix contains non-independent pairwise genetic distances

This is enough to show the practical workflow without making the vignette slow. The main goal here is not to maximize model complexity. Instead, we will use the staged workflow that is usually safest for real data:

  1. fit a one-raster Gaussian scale model
  2. compare it to a standard fixed-raster model
  3. only then add a second raster and inspect whether the fitted scales still behave sensibly
library(terradish)
library(terra)

data(melip)
melip.forestcover <- terra::unwrap(melip.forestcover)
melip.altitude <- terra::unwrap(melip.altitude)
melip.coords <- terra::unwrap(melip.coords)

keep <- 1:8
melip.Fst <- melip.Fst[keep, keep, drop = FALSE]
coords <- melip.coords[keep]

3.1 Step 1: Build a conductance surface with the original raster

Unlike the standard fixed-raster workflow, we do not pre-scale the raster with scale_covariates() here. The Gaussian conductance model smooths the raw raster first, then standardizes the active-cell values internally at each parameter evaluation.

covariates <- melip.forestcover
names(covariates) <- "forestcover"

surface <- conductance_surface(
  covariates,
  coords,
  directions = 8,
  saveStack = TRUE
)

Two details matter here:

  • saveStack = TRUE is required, because the Gaussian conductance model needs the retained raster stack as its smoothing domain.
  • We are fitting a smoothing scale for the raster itself, so the original raster values need to be available.

3.2 Step 2: Create the Gaussian scale-aware conductance model

gaussian_model <- gaussian_smoothed_loglinear_conductance(surface)

This conductance model will estimate two parameters:

  • forestcover: the conductance coefficient
  • sigma.forestcover: the Gaussian smoothing scale on the natural distance scale

The same mechanism also supports interactions and polynomial terms after smoothing, but it is usually better to start with the simplest one-raster model you can justify.

3.3 Step 3: Fit the one-raster Gaussian scale model

optimizer = "auto" currently resolves to BFGS for this conductance model. That is intentional: the native Gaussian scale path supports analytic gradients, and BFGS is the stable first optimizer for the joint beta + sigma parameter vector.

fit_gaussian <- terradish(
  melip.Fst ~ forestcover,
  data = surface,
  conductance_model = gaussian_model,
  measurement_model = mlpe,
  optimizer = "auto",
  leverage = FALSE,
  control = NewtonRaphsonControl(maxit = 12, verbose = FALSE)
)

fit_gaussian
#> Conductance surface estimated by maximum likelihood
#> Call:   terradish(formula = melip.Fst ~ forestcover, data = surface, 
#>     conductance_model = gaussian_model, measurement_model = mlpe, 
#>     leverage = FALSE, optimizer = "auto", control = NewtonRaphsonControl(maxit = 12, 
#>         verbose = FALSE))
#> 
#> Coefficients:
#>       forestcover  sigma.forestcover  
#>          -0.01596            0.02250  
#> 
#> Loglikelihood: 111.8887 (6 degrees freedom)   AIC: -211.7773

3.4 Optional speed-up: coarse-raster warm starts

Gaussian scale optimization can be expensive because every likelihood evaluation has two costly pieces:

  1. smooth the raster at the proposed sigma
  2. solve the graph Laplacian to get resistance distances

For large rasters, you can ask terradish() to optimize first on one or more aggregated rasters and then refine the result on the original surface:

fit_gaussian_coarse <- terradish(
  melip.Fst ~ forestcover,
  data = surface,
  conductance_model = gaussian_model,
  measurement_model = mlpe,
  approximation = "coarse_raster",
  approximation_control = list(
    factor = c(4, 2),
    exact_refine = TRUE
  ),
  optimizer = "auto",
  leverage = FALSE,
  control = NewtonRaphsonControl(maxit = 12, verbose = FALSE)
)

The coarse stages rebuild the Gaussian smoother on each aggregated raster, but they keep the full-resolution sigma bounds and unit conversion. That means a coarse-stage sigma is still interpreted in the original map units. With exact_refine = TRUE, the final model is not a coarse approximation; it is the full-resolution fit initialized from the coarse result.

3.5 Step 4: Inspect the fitted one-raster scale

coef(fit_gaussian)
#>       forestcover sigma.forestcover 
#>       -0.01596426        0.02250000

The conductance coefficient tells us whether smoothed forest cover is associated with higher or lower conductance. The scale parameter is already on its natural scale, so we can summarize it directly:

coef(fit_gaussian)[["sigma.forestcover"]]
#> [1] 0.0225

gaussian_scale_summary() converts the fitted sigma values into:

  • the native raster distance scale
  • the internal optimization scale and its conversion factor
  • raster cell widths
  • one-dimensional Gaussian half-widths
  • two-dimensional radial extents that contain a chosen amount of kernel mass
gaussian_scale_summary(fit_gaussian)
#>     covariate  sigma sigma_lower sigma_upper sigma_internal sigma_conversion
#> 1 forestcover 0.0225          NA          NA            0.5            0.045
#>   sigma_conversion_mode native_unit sigma_cells_x sigma_cells_y    axis_50
#> 1                  cell     degrees           0.5           0.5 0.01517602
#>    radial_50    axis_95 radial_95
#> 1 0.02649173 0.04409919 0.0550743

That table is often the quickest way to interpret the fitted smoothing scale. For example, radial_95 is the radius that contains approximately 95% of the Gaussian kernel mass, while sigma_cells_x and sigma_cells_y show how broad the smoothing kernel is relative to the raster resolution.

You can also visualize the fitted kernel directly. The sigma plot shows the Gaussian weight curve over distance for each fitted scale parameter, with a vertical dashed line at the fitted distance containing 90% of the one-dimensional kernel mass and a shaded uncertainty band for that distance. Each panel is also annotated with:

  • the fitted sigma
  • the fitted 90% kernel-mass distance
  • the corresponding confidence interval bounds
plot(fit_gaussian, type = "sigma")
Fitted Gaussian kernel with uncertainty band. The dashed line marks the distance containing 90% of the one-dimensional kernel mass.

If you already know how to convert your map units into a more interpretable distance scale, you can relabel the plot directly. For example, if one map unit corresponds to one meter, then multiplying by 0.001 reports distances in kilometers:

plot(
  fit_gaussian,
  type = "sigma",
  distance_per_map_unit = 0.001,
  distance_unit = "km"
)
Fitted Gaussian kernel with x-axis relabeled in kilometers.

3.6 Step 5: Compare against a standard fixed-raster fit

The scale-aware fit is easiest to interpret when it is compared directly to the same model without an estimated sigma.

fit_fixed <- terradish(
  melip.Fst ~ forestcover,
  data = surface,
  conductance_model = loglinear_conductance,
  measurement_model = mlpe,
  optimizer = "auto",
  leverage = FALSE,
  control = NewtonRaphsonControl(maxit = 12, verbose = FALSE)
)

fit_fixed
#> Conductance surface estimated by maximum likelihood
#> Call:   terradish(formula = melip.Fst ~ forestcover, data = surface, 
#>     conductance_model = loglinear_conductance, measurement_model = mlpe, 
#>     leverage = FALSE, optimizer = "auto", control = NewtonRaphsonControl(maxit = 12, 
#>         verbose = FALSE))
#> 
#> Coefficients:
#> forestcover  
#>     0.05858  
#> 
#> Loglikelihood: 111.8835 (5 degrees freedom)   AIC: -213.767
aic_table(
  list(fit_gaussian, fit_fixed),
  mod_names = c("Gaussian scale-aware", "Fixed raster")
)
#>                  model K       AIC Delta_AIC AIC_wt Cum.wt   loglik
#> 2         Fixed raster 5 -213.7670    0.0000   0.73   0.73 111.8835
#> 1 Gaussian scale-aware 6 -211.7773    1.9897   0.27   1.00 111.8887

The two fits use the same response, sites, graph, and MLPE likelihood, so their AIC values have a common basis. The scale-aware model’s parameter count includes the estimated smoothing scale. In a larger analysis, declare the candidate scale and formula set before comparing it, and report the search that was performed.

At this stage, the main question is not simply “which AIC is smaller?” A more useful question is:

  • does sigma.forestcover stay away from the bounds?
  • is the fitted smoothing scale distinguishable from the bounds and supported by the raster resolution and sampled domain?
  • is the scale-aware fit at least competitive with the simpler fixed-raster version?

If the answer is yes, then adding another raster is more defensible.

When tails are weakly supported at focal sites, you can request focal-support clamping directly in prediction:

fitted_conductance_focal <- conductance(
  surface,
  fit_gaussian,
  support = "focal",
  support_probs = c(0.01, 0.99),
  clamp_covariates = "forestcover"
)

4 Stage 2: Add a second raster only after sigma looks sensible

Once the one-raster scale parameter looks stable enough to trust, we can add a second raster and inspect whether the scale estimates remain interpretable.

covariates_two <- c(melip.altitude, melip.forestcover)
names(covariates_two) <- c("altitude", "forestcover")

surface_two <- conductance_surface(
  covariates_two,
  coords,
  directions = 8,
  saveStack = TRUE
)
fit_gaussian_two <- terradish(
  melip.Fst ~ forestcover + altitude,
  data = surface_two,
  conductance_model = gaussian_smoothed_loglinear_conductance(surface_two),
  measurement_model = mlpe,
  optimizer = "auto",
  leverage = FALSE,
  control = NewtonRaphsonControl(maxit = 12, verbose = FALSE)
)

fit_gaussian_two

#> 2       0.50000 0.01517602 0.02649173 0.04409919 0.0550743

This is exactly the point where the staged workflow helps. If one or more sigma estimates now collapse to the lower bound, or drift toward the upper bound, that is useful information. It suggests one of several things:

  • the added raster may not need smoothing at all
  • the data may not support estimating multiple scales simultaneously
  • the smaller one-raster scale was not as stable as it first appeared

That does not mean the model failed. It means the scale parameters are telling you that the data may prefer a simpler spatial structure.

In the small melip subset used here, that is exactly the kind of pattern to watch for: the one-raster forestcover scale can be inspected on its own before adding altitude. After altitude is added, one or both fitted scale parameters may move toward the lower bound, which is a cue to proceed cautiously rather than immediately adding more landscape terms.

5 Important current limitations

This first version is intentionally focused. Right now it supports:

  • additive formulas made of raw numeric raster names
  • interactions among numeric raster names
  • polynomial/arithmetic terms such as I(forestcover^2)
  • one Gaussian scale parameter per selected raster
  • joint optimization through analytic gradients and BFGS
  • opt-in coarse-raster starts through approximation = "coarse_raster"

It does not yet support:

  • factor-valued raster layers
  • leverage / partial_X diagnostics

It does now support conditional-on-sigma marginal-association plotting, so you can inspect conductance and response-scale curves after fitting, but the leverage machinery is still intentionally disabled.

6 Where to go with your analysis

If this workflow looks reasonable for your data, practical steps are:

  1. Fit a small one-raster model first and inspect sigma.
  2. Compare it to a standard fixed-raster loglinear_conductance fit.
  3. Add additional rasters only after the one-raster scale parameter behaves sensibly.
  4. Treat boundary-hitting sigma estimates as a model-selection signal, not just an optimization nuisance.
  5. Reproject rasters before interpreting smoothing distances, because longitude/latitude rasters report sigma in degrees.

This staged approach makes it easier to assess whether the likelihood identifies an interior Gaussian smoothing scale under the fitted model. An identified smoothing scale is not, by itself, an identified movement or ecological-process scale.

7 Quick reference: the full scale-optimization workflow

library(terradish)

# 1. Build the surface from the ORIGINAL raster; do not pre-smooth it
surface <- conductance_surface(covariates, coords, directions = 8,
                               saveStack = TRUE)

# 2. Scale-aware conductance model: sigma is estimated, not fixed. The model
#    is built from the surface itself; sigma_upper bounds the search in map
#    units, and defaults to the retained raster extent's diagonal when left NULL.
cm <- gaussian_smoothed_loglinear_conductance(surface)

# 3. Fit; theta and sigma.<layer> are estimated jointly
fit <- terradish(melip.Fst ~ altitude, data = surface,
                 conductance_model = cm, measurement_model = mlpe)

# 4. Read the fitted scale. `sigma` is in map units, so reproject a
#    longitude/latitude raster first or it will be reported in degrees.
gaussian_scale_summary(fit)   # sigma + kernel-mass distances in map units

# 5. Sanity check against a fixed-raster fit of the same covariate
fit_fixed <- terradish(melip.Fst ~ altitude, data = surface,
                       conductance_model = loglinear_conductance,
                       measurement_model = mlpe)
aic_table(list(fit, fit_fixed),
          mod_names = c("Scale-aware", "Fixed raster"))

# 6. Recover the conductance surface at the estimated scale
plot(conductance(surface, fit))

8 Summary of key functions

Function Purpose
conductance_surface() Build the graph from the original, unsmoothed raster
gaussian_smoothed_loglinear_conductance() Conductance model that estimates sigma jointly with theta
terradish() Fit the scale-aware model
gaussian_scale_summary() Fitted sigma per layer and corresponding Gaussian kernel-mass distances
conductance() Extract the fitted conductance surface at the estimated scale
aic_table() Compare the scale-aware fit against a fixed-raster fit
